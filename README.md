# Diwali Sales data analysis

## Objective
We are prodided with the Diwali data set. 
Obejctive is to analyse the sales data set and perform EDA and draw useful insights.

## Data set
Given Diwali sales data set. This dataset contains sales of the Diwali sales. This dataset contains the following features. 
- User_ID : This contains the ID of the customers. It has non-null values.
- Cust_name : It contains the customer name. It has non-null values.
- Product_ID : It contains product ID. It has non-null values.
- Gender : It contains the gender of the customer. It has non-null values.     
- Age Group : It contains the age group of the customer. It has non-null values.       
- Age : It contains the age of the customer. It has non-null values.            
- Marital_Status : It contains the marital status of the customer. It has non-null values.
- State : It contains the state of the customer. It has non-null values.
- Zone : It contains the zone(area) of the customer. It has non-null values.
- Occupation : It contains the occupation of the customer. It has non-null values.
- Product_Category : It contains the category of the product. It has non-null values.
- Orders : It contains the orders. It has non-null values. 
- Amount : It contains the amount spent of the perticular product. It has null values.
- Status : This is the empty column. 
- unnamed1 : This is empty column.

### Total number of rows in data set: 11251
### Total number of columns in data set: 13
